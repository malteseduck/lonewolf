# NNNN. Title, as the decision

- Status: Accepted (or: Superseded by NNNN, with a one-line reason)
- Date: YYYY-MM-DD (when the owner first decided)
- Amended: YYYY-MM-DD (the latest amendment; leave out until there is one)
- Supersedes: NNNN, if this replaces a reversed decision

## Context

What prompted it: the problem, what was tried, what the owner said. Short. An amendment adds a
paragraph for what prompted it.

## Decision

What is decided now, stated so an agent can check work against it. An amendment rewrites this to
the current decision.

## Consequences

What follows: what to do, what not to do, where it lives in the code or docs.

## Changes

- YYYY-MM-DD: one line per amendment, what changed and why. (Leave out until there is one.)
