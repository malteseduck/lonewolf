# 0013. Decoration never takes the pages' space

- Status: Accepted
- Date: 2026-09-30

## Context

The bronze clockwork gear round the book was taking room from the pages.

## Decision

Decoration around the book (the clockwork) must not cost the pages space. The pages come first.

## Consequences

Spec 6.1. Size decoration into the margins the spread leaves, never shrink the spread for it.
