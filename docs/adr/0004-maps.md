# 0004. Maps: the book's own printed map, upscaled by a Gemini repaint over names set in type, shown in sepia

- Status: Accepted
- Date: 2026-10-05 (printed map only); the chain 2026-10-06; the font 2026-10-07; sepia 2026-10-07
- Amended: 2026-10-20

## Context

The player once drew its own maps: replicas of the printed maps stamped with engraved symbols,
made-up places per section, town plans, and travel on the map. The owner dropped all of it
(2026-10-05).

The upscale was tried on Book 4: Real-ESRGAN alone is exact but flat and keeps smeared lettering;
re-opening letter holes by script broke other letters; local Stable Diffusion with ControlNet
reinvented symbols and lettering. A Gemini (Nano Banana) repaint gave the look the owner wants but
garbled names. On Book 1, copying the scan's spellings gave a near copy the owner found boring, edit
prompts broke labels that were right, and pasting the scan's lettering onto the paint smudged.
Erasing every place name and setting it in type before the repaint worked. History in
`docs/reference/map-upscale.md`.

Finish used to set every place name again whenever no label was ticked reset. On Book 12's round 3
the owner ticked nothing, expecting the round as it was, and got all 30 names set again; where
Gemini had moved a name, the new one landed beside the remains of Gemini's (a doubled "Vorndarol").

The names need one clean type Gemini can copy and the player can read at 4K. IM Fell English with a
light halo was tried first; the owner wanted it bigger and bolder, and no halo. Cabin SemiBold, a
free Gill Sans relative, suits maps lettered in a plain sans. Book 12's map is lettered by hand in
thin marker, and Cabin looked like set type on it; the owner asked that a map's font be a general
mechanism rather than a Book 12 exception.

The 4K repaints are in full colour; the player's pages are aged parchment and ink.

## Decision

- **Only the printed map.** A book's map is the one printed in it, restyled at runtime (`maps.js`),
  and nothing else: no replicas, made-up places, town plans or travel on the map. Every choice is
  made on the story page.
- **The upscale chain**, each map: upscale the scan, draft and check the label list, erase the place
  names, set them again in type, have Gemini repaint (the owner runs it), check, re-set any name
  Gemini garbled at 4K, enlarge to 4K WebP.
- Gemini paints a rich repaint in the map's own style; colour and style changes are fine if the map
  stays close enough. Nothing added: no fruit, foliage, ornaments, new trees, ships or buildings.
- A new round starts from a new prompt in a new chat. No edit prompts.
- The owner corrects the label list in the editor after the OCR draft. The map steps are scripted;
  the one AI step is step 3's **Find missed labels**, pressed by the owner: Claude Sonnet, called
  headless with only the map's tiles and a short request, lists names outside the boxes, which come
  in marked for the owner to check. The agent still does not review the draft itself. Step 3's
  **Check names**, a script, checks every wording against the downloaded books' own text and the
  other checked maps, and suggests the name a misread is close to; the owner picks, or marks a
  map-only name right as it is.
- **Finish sets again exactly what is ticked**: the labels ticked reset (and fix), or, with none
  ticked reset, only the fix labels. With nothing ticked it is an upscale only and Gemini's names
  stand. A checkbox on the Finish step, "Set every place name again", unchecked by default and on
  every load, gives the old behaviour; it is greyed out while any label is ticked reset. The step
  says what Finish will do before it runs.
- **Lettering.** Place names are set with no halo, each one-line name pulled most of the way from its
  own fitted size to the map's usual size (the median of its names fitted to their own ink), except a
  name fitted over 1.25 times that usual size (a title, a region), which keeps its own. `maps/<code>/font.txt` sets a map's font: line 1 names a font file in `tools/fonts/`, used
  for capitals and mixed case alike and honoured by every step that sets or previews the names; an
  optional line 2 describes the lettering to Gemini in place of "clean sans-serif type". A map with no
  `font.txt` gets Cabin SemiBold. A book's `font.txt` is the owner's choice for that map: an agent does
  not change it, remove it, or override it on the command line without the owner's say-so.
- Book 12: `DarklandHand-Regular.ttf`, our own font (`tools/map_font.py`), described as "hand-lettered
  in an even felt pen, in angular, runic-looking letters (diamond O, zigzag S, pointed bowls)". A map's
  font may be one we draw ourselves when no free font matches its hand: built by a script in `tools/`,
  OFL, committed in `tools/fonts/` like the rest. Darkland Serif (2026-10-20) is the second: Darkland
  Hand's nib, still angular (owner), with Book 9's wedge serifs, rounded-diamond O and bowls, round C.
- Book 9: `DarklandSerif-Regular.ttf` (owner, 2026-10-20), its line 2 describing that font's angular,
  serifed capitals. Book 10: the same font (owner, 2026-10-20), its line 2 naming capitals and lower case.
- Book 11: `DarklandHand-Regular.ttf` (owner, 2026-10-20), its line 2 naming capitals and lower case.
- The OCR draft and Claude's finds keep each name's printed case (owner, 2026-10-20): Book 10 mixes
  them, and capitals everywhere had to be retyped.
- **Sepia.** The map is shown in sepia like the old scan and the rest of the book, whether it is the
  4K upscale or the printed scan.

## Consequences

- The old map code is in git history before 2026-10-05; its symbols are kept in git-ignored
  `art/reference/map-symbols/from-game/`. Do not bring them back. Improving a map means upscaling the
  printed one, not redrawing it.
- The chain and its tools are in `docs/reference/map-upscale.md`; each map's prompt opens with
  `maps/<code>/style.txt`. Everything made from a map stays in `data/projectaon/<code>/` (spec 3).
- `map_letter.py` takes `--all` for setting every name again; `serve.py` passes it for `?all=1`.
  Do not make that the default again without the owner.
- `tools/serve.py` (`_fonts`) passes the font to `map_letter.py` for the Letter and Finish steps; the
  map editor's preview draws in it; `map_labels.py prompt` reads line 2. Any new tool that sets map
  names reads it too.
- A font named there must be free to redistribute, with its licence and source in
  `tools/fonts/README.txt`. Adding one needs the owner's go-ahead (AGENTS.md). Choosing a font for
  another map: letter a side-by-side trial against the scan, let the owner pick, write `font.txt`.
  Keep names in their printed case in the label list, so a hand font's lower case is used. Do not
  switch fonts across all maps without the owner.
- The sepia restyle is applied at runtime in `maps.js` (`docs/reference/interface.md`); the files on
  disk keep their colour.
